Agent Setup Guide

Build your own
AI assistant.

Not a chatbot in a browser tab. An assistant that lives on your computer, that you text like a person, that can actually read your files, run your errands and remember you.

You won't install anything by hand. You'll paste one prompt, and an AI does the whole setup while you watch.

3 steps 0 things to download ~20 min, mostly waiting

What you're actually building

A free program called OpenClaw runs quietly on your computer. You talk to it from your phone over Telegram, like texting a friend.

The difference between this and ChatGPT: it has hands. It reads and writes your files, searches the web, runs commands, browses sites while logged into your accounts, checks your email and calendar, and remembers everything across every conversation. You point it at an AI subscription you probably already pay for, and it becomes the thing that actually does the work.

The entire requirement list: a computer that stays awake, and one AI subscription. That's it. Everything else installs itself.

Three steps

1

Pick a brain

The only thing here that costs money, and you may already pay for it. Pick one — you can add the other later.

Most capable

Claude

Pro $20/mo · Max $100–200/mo · claude.ai

  • Best at long, messy, multi-step work
  • Strongest at code and editing files
  • Pro is enough to start. Max is for running it hard, all day
Already have it

ChatGPT

Plus $20/mo · Pro $200/mo · chatgpt.com

  • Works great, and most people already subscribe
  • Uses your existing login — no API bill
  • Plus has tighter limits. Fine for chatting on demand

Install that company's desktop app and sign in. That's all of step 1 — the app is what runs step 3 for you.

2

Stop your computer from sleeping

Your assistant only works while its computer is awake. It doesn't need to be a new machine or a spare one — your everyday laptop is fine. It just can't nap.

Mac: System Settings → Lock Screen → set the display and the computer to Never while plugged in. Leave it plugged in, lid open.
Windows: Settings → System → Power → set sleep to Never when plugged in.

Skip this and it still works — it just goes quiet whenever your computer does, and wakes when you do. Plenty of people start that way and only fix it once they want things happening overnight.

3

Paste this and let it build itself

Open the desktop app from step 1, turn on its ability to use your computer (next section), then paste this in and hit send. It installs everything, connects your phone, and checks its own work.

The whole setup, in one paste
I want to set up OpenClaw on this computer so I have my own always-on AI
assistant that I can text from my phone. Please do the entire setup for me.

Assume I am not a developer. Do not ask me to make technical decisions, and
explain each step in plain language as you go. Do the work yourself rather
than handing me instructions to follow.

Steps:

1. Read the official guide at https://docs.openclaw.ai/start/getting-started
   first, and follow that rather than anything you remember.
2. Install OpenClaw by running:
   curl -fsSL https://openclaw.ai/install.sh | bash
   That script installs Node and anything else it needs on its own. Do not
   install Homebrew, Node, Git, a code editor, or a terminal app separately.
3. Run: openclaw onboard --install-daemon
   Walk me through the prompts. When it asks about the AI provider, sign in
   with my existing Claude or ChatGPT SUBSCRIPTION. Do NOT set up a
   pay-per-use API key or any billing account.
4. Set up Telegram so I can text it from my phone: help me create a bot with
   @BotFather, get the token, and lock it down so only my account can message
   it. Tell me exactly what to tap on my phone.
5. Verify it actually works. Run openclaw gateway status, then have me send a
   real Telegram message and confirm I get a reply. Do not tell me it's done
   until you have seen it reply.
6. Ask me a few questions about who I am and what I do, and write the answers
   into its memory files so it knows me from day one.

Rules: stop and ask me before anything that costs money, sends a message to
another person, or deletes files. At the end, give me a short list of what you
set up, where it lives, and three things I should try first.

It will ask permission before running things on your machine. That's normal, and it's the point — but read what it's about to do before you approve. Never approve something that deletes files or spends money if you don't understand it.

Letting the app touch your computer

Step 3 only works if the desktop app is allowed to run things. Both apps ship locked down, so this is the one setting you have to flip yourself.

ChatGPT: the setup happens in Codex, inside the ChatGPT desktop app. Point it at a folder on your computer and let it run commands there.

Claude: same idea — Claude Code, inside the Claude desktop app, pointed at a folder on your machine.

Approve as you go, at least at first. Letting it run without asking is faster, and it's where most people end up — but only after watching it work for a while. There's no undo on a command that already ran.

These menus move around as the apps update. If you can't find the setting, ask the app itself: "how do I let you run commands on my computer?" It knows its own settings better than any guide can stay current.

What we left out on purpose

Every other setup guide hands you a download list. Here's why this one doesn't.

Node.js, Homebrew, Git

The installer puts these in for you. If a guide tells you to download them first, that guide is out of date.

A fancy terminal — iTerm2, Warp, Ghostty

The terminal already on your computer is fine, and doing it this way you barely open it. These are for people who live in a terminal all day. You won't.

VS Code or any code editor

You're not writing code — your assistant is, and it edits its own files directly. Install an editor only if you personally want to sit and read the code.

A cloud server or VPS

Tempting, but it's a downgrade. A Linux box in a datacenter can't touch your messages, contacts, calendar, mail, photos or logged-in browser — which is most of what makes this feel like magic. Use your own machine.

A second computer or a Mac mini

Genuinely nice once you're hooked and want it running 24/7. Completely unnecessary to start.

API keys and credits

Your normal Claude or ChatGPT subscription is enough. Setting up billing at an API console is how people accidentally spend real money.

Once it's alive

Don't start with a big project. Start by proving to yourself it's real:

"What's on my calendar tomorrow?"
"Summarize this article for me: [link]"
"Watch this webpage and text me if the price drops."
"Go through my inbox and tell me what actually needs me."

Then let it get to know you. The whole thing gets dramatically better once it has real context on who you are and how you work — it writes that down and keeps it.

Later, when you want more

Don't set any of this up now. When you hit the moment where you want one, just ask your assistant to add it — it can do its own installs.

A password managerSomewhere safe for it to keep logins, instead of you pasting passwords into a chat window.
A private networkSo you can reach the home machine from anywhere without opening it up to the internet.
Version controlA free undo button for its memory and notes. You'll want this the first time it deletes something.
DiscordSeparate rooms — alerts here, logs there, one per project — for when a single Telegram thread isn't enough.
A voiceSo it can send voice notes instead of walls of text. Purely for fun. A lot of fun.
Web hostingSo it can build you dashboards and put them online. This page is an example of that.
